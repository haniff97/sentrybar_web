Get SentryBar on Your Mac

Compile in seconds using native Swift Package Manager or package the self-contained app bundle with persistent TCC designated requirements.

$ git clone https://github.com/haniff97/SentryBar
$ cd SentryBar
# Run directly (development)
$ swift run SystemMonitor
# Print all sensor readings (CLI)
$ swift run SystemMonitor --test
# Build the packaged .app
$ ./scripts/make-app.sh # -> dist/SentryBar.app
$ open dist/SentryBar.app
# Build the DMG installer
$ ./scripts/make-dmg.sh # -> dist/SentryBar.dmg (+ prints SHA-256)
